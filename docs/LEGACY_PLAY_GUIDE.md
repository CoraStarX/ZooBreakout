## 运行

Godot **4.7** 打开仓库根目录 → F5。开局固定浣熊（猴关在笼里，开锁救出）。

| 输入 | 作用 |
|------|------|
| WASD / 左摇杆 | 相对相机移动 |
| E / 手柄 A | 交互（黄柱标签 / 办公室金柜）；施工点前 HUD 先预览 Soft/强行、扣料与会留下的痕迹 |
| X / 手柄 X | 放下物品；在施工点旁＝存料（HUD 先提示存入/丢下） |
| G / 手柄 B | 叫嚷引开职员（冷却 6 秒，全队每天 4 次，用尽「嗓子哑了」） |
| T / 上十字键 | 投掷石子（需「投掷」才能＝猴；落点发声，冷却 8 秒） |
| Tab / 手柄 Y | 换控 |
| F·H / LB·RB | 跟随 / 待命 |
| V / 下十字键 | 放标记，队友前往 |
| Esc / 手柄 Start | 暂停菜单（操作说明、引导开关、音量、回标题） |
| F3 | 开发者调试面板（默认隐藏） |
| N | **【Debug 默认关】** 推进时段（原 T，已改给投掷） |
| R | **【Debug 默认关】** 跳过笼门解救（正式路径：打开同伴笼门） |

本局节奏：**白天**搜集原料——木料/绳索/金属（蓝点，金属稀缺，可冒险去职员工具间或趁职员停步从背后偷工具车）、捡施工套件（全图 1 个，挖洞/攀爬通用）、侦察职员（紫点）；**夜里**到西/南外墙分 3 档施工（挖洞每档 木料+金属，攀爬每档 绳索+金属，或套件顶 2 档），打通出园线后全队进出口。第 **5** 天封园检修为期限（`DayCycleParams`；Open 时长见同资源）。可选：打开同伴笼门解救、办公室夺回被没收的物资（背包与地上被收走的东西都在那里）。

被抓：物品进办公室金柜；送回笼内短押 15 秒（笼里可搜集零件，同伴可撬门营救），笼门当天加固；警戒升高会拉长 **Night-Patrol**。

### 員工可讀性沙盒 B（歷史狀態）

開啟 scenes/traversal/staff_readability_lab.tscn 並執行目前場景（Mac 可用 Fn+F6）。沿用 WASD／Space 移動；F3查看或重置感知統計；「複製統計」預設為追捕／搜索／歇崗摘要，「複製完整診斷」才附0.1秒警覺時間線與完整移動記錄。一名地面員工，每圈休息但仍可聽見；追捕到達只給回饋，不拘留／傳送。原移動入口與F5舊關卡保持。見 [docs/STAFF_READABILITY.md](STAFF_READABILITY.md)。

### 變形試玩 A（獨立原型）

在同一專案開啟 `scenes/forms/form_lab.tscn`，以編輯器「執行目前場景」遊玩。WASD 移動，Q 本體／猴切換；猴沿用 Space 跳躍／放手與意圖攀爬，本體不能跳躍。回本體不限冷卻，變猴需站穩且有空間。F5 仍執行舊正式世界。本階段沒有員工與新窄縫，B／C 待手玩放行。

變形A更新：靠牆／平台邊緣Q會在0.32公尺內自動調整到合法同層位置再變形；找不到才提示「這裡太窄」。不穿牆、不跨樓層，回本體與冷卻規則不變。上限在content/forms/form_params.tres調整。
