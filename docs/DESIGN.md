# Zoo Breakout — 设计共识

> 活文档。与立项讨论对齐；冲突时以本文件 + 近期变更为准。  
> 行动成本本轮计划见 [COST_REFACTOR.md](COST_REFACTOR.md)。

## Pitch

你扮演动物园里的动物，先逃出自己的展区，再解救同伴组成异能小队；用物种才能互补策划开放式集体出逃——缺对应才能则硬门槛做不了；可强行的点更吵、更慢、更易留痕。

## 支柱

1. **能力是互补的才能**：硬门槛处只有具备对应动词的动物能做；施工等通用行动两者皆可，但有擅长差异（Soft 快而安静 / 允许的 Hard 慢、吵、留痕）。门槛由点位资料 `allow_hard` 等栏位表达，不写死物种名。
2. **解救即成长**：新动物 = 新动词，不是纯数值。
3. **计划感**：谁去哪、何时、带什么，重于纯反应。
4. **失败可解读**：被抓可归因到缺信息 / 缺能力 / 执行失误。

## 已锁定决策

| 项 | 决议 |
|----|------|
| 引擎 / 平台 | Godot 4.7 · Steam |
| 操控 | 单机换控；未控 Follow/Hold；**危险区仅提示，跟随不强制中断**（前往标记点见后续 R7） |
| 进度 | 逃出本区 → 解救 → 解锁换控；终局：**所有同伴都已解救且全员到达出口**才算出园（不得单独通关；还有同伴在笼里，**或同伴被抓短押中**，出口都拒绝并点名提示；被抓的同伴须等它出来一起走） |
| 开局 | **固定浣熊**（`AnimalDef.can_start`；猴开局非正式设计，已停用） |
| 能力池 | 动词集合；动物是载体；路线认动词不认物种 |
| P0/P1 池子集 | 巧手、攀爬、挖掘、冲撞、钻缝；本轮加 **投掷（THROW）**（猴）。钻缝＝浣熊（与巧手并列）；目前只有挖洞线认它，笼门不认 |
| 点位强行 | 点位资料 `allow_hard`（默认 true）；开锁 / 小缝隙 / 高处与施工**最后一档**禁止强行；其余施工档可强行（代价：时间×3、噪音×2、痕迹×2）。**强行不直接升全局 Alert** |
| 笼门才能 | 笼门要求的是**救援者**的才能，不得要求被关者自己的；浣熊笼、猴笼皆=**开锁（巧手）**，`allow_hard=false`；载入时 `CageDependencyCheck` 检出「只有 A 能开、A 却关在门后」即报错 |
| 出园路线 | 两条都须「浣熊＋猴」可通关：**挖洞线**＝钻缝或巧手（浣熊）；**攀爬线**＝攀爬（猴擅长）。中间档对方可强行，最后一档只能擅长者 Soft。全图材料只够一条，逼玩家选线 |
| 背包 | 容量按 AnimalDef：**浣熊 4 / 猴子 2**；重物由 `ItemDef.heavy`（`content/items/*.tres`）标记，现仅**挖掘套件、攀爬套件**：移速 −40%（`heavy_speed_mult`）、禁用攀爬。绳/木/金属不是重物，只占格。**背套件时「高处」搜集点不算有攀爬，只能慢慢拿少量**（与没有攀爬的动物相同） |
| 放下 / 存料 | **X**：在施工点旁＝把该点配方用得到的原料和该线套件全部存进点位（白天也可，不算施工）；其他地方＝放下一件到地上（有重物先放重物），E 捡回。施工先扣点位存料再扣背包，取消时退回原处。存料与地上物品跨天保留、被抓不没收。**Alert3 只收缴地上物品（`ground_items`），施工点存料不收**。路线完工时剩余存料清空并提示种类数量。HUD 背包下方常驻显示 X 当前行为（存入哪个点 / 丢下哪件），与实际判定同一函数 |
| 日常循环 | 准备循环 + 具名套件 + 通路进度（非深合成） |
| 被抓 | 警戒升档、抄当前控制者物品进办公室、送回本区**短押 15 秒**（笼内可活动/搜集零件；职员守门；笼门当天**加固**：开锁多耗 1 零件，无零件则耗时×2）；同伴可撬门提前营救。2026-10-09 由「关禁闭至下一 Open」改（原因：夜里被抓会干等几十秒，无事可做） |
| 昼夜 | Open 宜观察搜集；挖洞/攀爬/破笼门仅夜间；职员视线被墙阻挡。Open 时长入 `DayCycleParams`（重构期试 **180s**） |
| 警戒 | = 工作人员警戒。噪音本身不加 Alert；**痕迹被发现或被看见**才升档（拆笼门零件被发现可 +1）。升档后果：Alert2 听觉×1.25；3 施工噪音×1.3 起 + 地面材料收缴（仅地上物品，不含施工点存料）；4 awareness 加速 + 歇岗缩短 + UI 预警「再升一档将全园搜查」；5 全园搜查并中止施工（须明示原因）。**不做**视野范围增加、搜集点减产。同一痕迹 Alert 只结算一次 |
| 叫嚷 | 每日上限 4 + 冷却；用尽提示「嗓子哑了」；不计 Alert |
| 时间 | 开放 / 闭园过渡 / 夜间（巡逻段→歇岗安全窗） |
| 视角 | HD2D ~45° 斜俯视 |
| 地图 | 一座连续园 + 分区解锁 |
| 发行 | 按 EA 门槛建设；可跳过 EA 直接 1.0 |

## Backlog

- **浣熊被抓后同伴无法营救**：浣熊笼只认巧手，猴没有，只能等短押 15 秒结束。本轮不做；日后考虑给笼门第二种开法（须仍符合「要求救援者的才能」）或新动物。
- **挖掘（DIG）**：标签保留在 `CapabilityIds`，现有路线均不要求；留给日后獾类（新动词入队时再设计用途）。

## P0 验证题

灰盒下：玩家是否会主动换控、用第二动物降风险，并理解「硬门槛必须换控；可强行处 Soft/Hard 代价可读；留痕被发现能归因」？

- **Keep**：会换控；会用第二只降风险；被拒（`allow_hard=false`）或 Hard 留痕被发现说得出原因。
- **Kill**：只会一条攻略；有第二只不用；跟随是主要挫败源。
