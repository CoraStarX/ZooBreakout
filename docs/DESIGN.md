# Zoo Breakout — 设计共识

> 活文档。与立项讨论对齐；冲突时以本文件 + 近期变更为准。

## Pitch

你扮演动物园里的动物，先逃出自己的展区，再解救同伴组成异能小队；用物种能力互补策划开放式集体出逃——缺某只动物也能硬闯，但更危险。

## 支柱

1. **能力互补，非能力门槛**：技能降低风险/操作；极少数教学可硬锁。
2. **解救即成长**：新动物 = 新动词，不是纯数值。
3. **计划感**：谁去哪、何时、带什么，重于纯反应。
4. **失败可解读**：被抓可归因到缺信息 / 缺能力 / 执行失误。

## 已锁定决策

| 项 | 决议 |
|----|------|
| 引擎 / 平台 | Godot 4.7 · Steam |
| 操控 | 单机换控；未控 Follow/Hold；危险区自动待命 |
| 进度 | 逃出本区 → 解救 → 解锁换控；终局：已解救队伍同步出园 |
| 开局 | 不固定；新档手动选；首发浣熊/猴；P0 默认浣熊 |
| 能力池 | 动词集合；动物是载体；路线认动词不认物种 |
| P0/P1 池子集 | 巧手、攀爬、挖掘、冲撞 |
| 日常循环 | 准备循环 + 具名套件 + 通路进度（非深合成） |
| 被抓 | 警戒升档、抄当前控制者物品进办公室、送回本区**短押 15 秒**（笼内可活动/搜集零件；职员守门；笼门当天**加固**：开锁多耗 1 零件，无零件则耗时×2）；同伴可撬门提前营救。2026-10-09 由「关禁闭至下一 Open」改（原因：夜里被抓会干等几十秒，无事可做） |
| 昼夜 | Open 宜观察搜集；挖洞/攀爬/破笼门仅夜间；职员视线被墙阻挡 |
| 警戒 | = 工作人员警戒；升档→声敏↑、夜巡休息时刻后移→安全夜窗缩短 |
| 时间 | 开放 / 闭园过渡 / 夜间（巡逻段→歇岗安全窗） |
| 视角 | HD2D ~45° 斜俯视 |
| 地图 | 一座连续园 + 分区解锁 |
| 发行 | 按 EA 门槛建设；可跳过 EA 直接 1.0 |

## P0 验证题

灰盒下：玩家是否会主动换控、用第二动物降风险，并理解「有动词更稳 / 无动词可硬闯」？

- **Keep**：会换控；会用第二只降风险；硬闯失败说得出原因。
- **Kill**：只会一条攻略；有第二只不用；跟随是主要挫败源。
