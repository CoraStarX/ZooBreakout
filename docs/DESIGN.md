# Borrowed Shapes — 現行設計基線

單角色擬態：玩家在本體與已解鎖形態間切換，以體型與能力通過空間。這份文件只記已驗收核心，不新增完整遊戲循環承諾。

## 已驗收規則

- WASD／方向鍵／左搖桿移動；Q切換本體與猴形態；Space統一猴形態跳躍、跨越、跳下與攀爬放手。本體不能跳躍。
- 意圖附牆與屋頂下牆沿用現行規則；翻上、落地、邊緣保護、跳躍預覽與鎖定、完整路徑／支撐檢查不變。
- 變成非本體需已解鎖、冷卻完成並接地；原位空間不足時僅在既定0.32m上限內尋找合法同層擺放，不穿牆或跨樓層。
- 成功變成非本體啟動冷卻；回本體不受冷卻限制。失敗不改形態、不耗冷卻、不發變形聲。
- 形態名稱、冷卻、成功與拒絕訊息須可讀；關閉被動提示後仍保留短暫操作訊息。
- 噪音走Bus.noise_made，其他角色／形態／回饋沿用本地訊號。
- 保持45°正交、接地陰影與遮擋淡出；F3提供診斷、重置與複製，恢復異常仍視為Bug。

精確判定與參數沿用[MOVEMENT_SLICE.md](MOVEMENT_SLICE.md)與[FORMS_SLICE.md](FORMS_SLICE.md)，其逐輪試驗段落視為歷史，不擴充當期範圍。
