## 运行

Godot **4.7** 打开仓库根目录 → F5。先选开局动物（浣熊/猴）。

| 输入 | 作用 |
|------|------|
| WASD / 左摇杆 | 相对相机移动 |
| E / 手柄 A | 交互（黄柱标签 / 办公室金柜） |
| Tab / 手柄 Y | 换控 |
| F·H / LB·RB | 跟随 / 待命 |
| T | **【Debug 默认关】** 推进时段 |
| R | **【Debug 默认关】** 跳过笼门解救（正式路径：打开同伴笼门） |

本局节奏：**白天**搜集原料——木料/绳索/金属（蓝点，金属稀缺，可冒险去职员工具间或趁职员停步从背后偷工具车）、捡套件、侦察职员（紫点）；**夜里**到西/南外墙分 3 档施工（挖洞每档 木料+金属，攀爬每档 绳索+金属，或套件顶 2 档），打通出园线后全队进出口。第 7 天封园检修为期限。可选：打开同伴笼门解救、办公室夺回物资。

被抓：物品进办公室金柜；送回笼内短押 15 秒（笼里可搜集零件，同伴可撬门营救），笼门当天加固；警戒升高会拉长 **Night-Patrol**。
